# Reimplementation: Fine-Grained Uncertainty Decomposition in Large Language Models: A Spectral Approach

This repository contains a Python reimplementation of the paper:

**"Fine-Grained Uncertainty Decomposition in Large Language Models: A Spectral Approach"**
by Nassim Walha, Sebastian G. Gruber, Thomas Decker, Yinchong Yang, Alireza Javanmardi, Eyke Hüllermeier, Florian Buettner
